# Wajeeha Ayaz — Video Editor Portfolio

A cinematic video editing portfolio showcasing YouTube videos, documentaries, reels, and short-form content.

## About

This portfolio is built to present Wajeeha Ayaz's video editing work, editing approach, and project inquiries in a clean, cinematic, editorial style.

## Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Formspree for contact form submissions

## Run Locally

No Node.js or npm setup is required.

Simply open the project in VS Code and run it with **Live Server**.

### Project Structure

```text
index.html

  script.js

  projects/
  ...
videos/
  ...
```
